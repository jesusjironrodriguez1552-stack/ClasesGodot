else if:
Múltiples Rutas

▶ VIDEO: CONDICIONALES PARTE 2 — ELSE IF (CLASE 6)

El if / else solo tiene dos caminos: sí o no. Hoy aprenderás a crear múltiples rutas con else if. El código ya no decide entre dos opciones, sino entre las que necesites.

¿Qué es el else if?

Imagina un semáforo. No solo tiene dos estados (verde/rojo), tiene tres: verde, amarillo y rojo. Con solo un if / else no puedes modelar eso. El else if te permite agregar tantos casos intermedios como necesites.

La computadora los evalúa en orden, de arriba hacia abajo. En cuanto encuentra uno que sea true, ejecuta ese bloque y salta todos los demás. Si ninguno es verdadero, cae al else final.

La Estructura Completa:

if (condición 1) {
// se ejecuta si condición 1 es TRUE
} else if (condición 2) {
// solo se evalúa si condición 1 fue FALSE
} else if (condición 3) {
// solo se evalúa si las anteriores fueron FALSE
} else {
// se ejecuta si NINGUNA condición fue TRUE
}

Ejemplo real — Sistema de notas:

La computadora evalúa cada condición de arriba hacia abajo. Como 75 >= 90 es false, salta al siguiente. Como 75 >= 70 es true, ejecuta ese bloque y se detiene.

let nota = 75;

if (nota >= 90) {
  console.log("🏆 Sobresaliente");
} else if (nota >= 70) {
  console.log("✅ Aprobado"); // ← esto se ejecuta
} else if (nota >= 50) {
  console.log("⚠️ En riesgo");
} else {
  console.log("❌ Reprobado");
}

⚠️ El orden importa muchísimo

Los else if se evalúan en el orden en que los escribes. Si pones primero una condición más amplia, las siguientes nunca se ejecutarán. Siempre escribe los casos más específicos primero y los más generales al final.

// ❌ MAL — el primer if atrapa todo, el else if nunca corre:
if (nota >= 50) { // atrapa 50, 70, 90...
  console.log("En riesgo");
} else if (nota >= 70) { // nunca llega aquí
  console.log("Aprobado");
}

// ✅ BIEN — del más específico al más general:
if (nota >= 90) {
  console.log("Sobresaliente");
} else if (nota >= 70) {
  console.log("Aprobado");
} else if (nota >= 50) {
  console.log("En riesgo");
}

¿Qué vas a construir?

Las apps reales no solo dicen "acceso denegado". Dicen exactamente qué está mal. Tú vas a programar esa lógica completa usando todo lo aprendido en las 6 clases.

  • 📦 Paso 1 (Clase 2): Crea usuarioCorrecto y clavecorrecta con los valores válidos (texto, con comillas).
  • 📦 Paso 2 (Clase 2): Crea usuarioIngresado y claveIngresada con lo que "escribe" el usuario.
  • ⚖️ Paso 3 (Clase 4): Crea usuarioOk y claveOk usando == para comparar.
  • 🔀 Paso 4 (Clase 5 + 6): Usa if / else if / else para los 4 casos:
    usuarioOk && claveOk → "✅ Acceso concedido."
    usuarioOk pero NO claveOk → "❌ Contraseña incorrecta."
    NO usuarioOk pero claveOk → "❌ Usuario no encontrado."
    ninguno → "🔴 Usuario y contraseña incorrectos."
  • 📢 Paso 5 (Clase 1): Usa console.log() para mostrar el resultado de cada caso.

Para combinar dos condiciones usa && (Y lógico). Ambas deben ser true al mismo tiempo:

if (usuarioOk && claveOk) {
  // solo entra aquí si LAS DOS son true
}
