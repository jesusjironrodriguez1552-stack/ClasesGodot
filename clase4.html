▶ VIDEO: VERDADERO O FALSO (CLASE 4)

La computadora solo entiende de blancos y negros. Hoy le enseñarás a comparar datos para saber si algo es Verdadero (true) o Falso (false).

¿Para qué sirve comparar en el código?

Imagina que estás en la puerta de un club y tienes que decidir quién entra y quién no. Para tomar esa decisión necesitas comparar: ¿tiene más de 18 años? ¿Su nombre está en la lista? ¿Pagó la entrada?

Las apps hacen esto millones de veces por segundo. Instagram compara si tu contraseña es correcta. Netflix compara si tienes suscripción activa. Un juego compara si tu puntaje supera el récord. Todo eso usa operadores de comparación.

Los 3 Operadores de Comparación:

>   Mayor que

Pregunta si el número de la izquierda es más grande que el de la derecha. Como preguntar "¿tengo más dinero que el precio?"

let resultado = 10 > 5;
// → true (10 sí es mayor)

<   Menor que

Lo contrario. Pregunta si el número de la izquierda es más chico. Como preguntar "¿mi edad es menor a la mínima?"

let resultado = 3 < 8;
// → true (3 sí es menor)

==   Igual a

Pregunta si dos valores son exactamente iguales. Ojo: se escriben dos iguales, no uno. Un solo = guarda datos (Clase 2), dos == comparan.

let resultado = 7 == 7;
// → true (son iguales)

💡 El Nuevo Tipo de Dato: Booleano

En las clases anteriores aprendiste dos tipos de datos: Textos (con comillas) y Números (sin comillas). Hoy aparece el tercero.

Los Booleanos solo tienen dos valores posibles: true o false. Sin comillas, sin números. Solo esas dos palabras. Piénsalos como el interruptor de la luz: está encendido o está apagado, no hay término medio.

Cuando haces una comparación, la computadora siempre te devuelve un Booleano. Es su forma de decirte "sí" o "no".

// La PC evalúa y responde con true o false:
let luzEncendida = true;  // Encendido
let luzApagada  = false;  // Apagado
let comparacion = 10 > 3;   // → true

Un programador novato rompió el sistema de contraseñas. ¡Encuentra la diferencia entre Asignar y Comparar!

El error más común del mundo

Este bug lo han cometido hasta los programadores con 10 años de experiencia. El problema está en que el signo = tiene dos usos completamente distintos en código:

  • Un solo = significa "guarda este valor en la caja". Lo usaste en Clase 2 para crear variables.
  • Dos iguales == significa "compara si estos dos valores son idénticos". Es lo que aprendiste hoy.

El código de abajo usa un solo = donde debería usar ==. En vez de comparar la clave ingresada con la secreta, está sobreescribiendo la variable. El sistema siempre dejará entrar a cualquiera, ¡es un fallo de seguridad!

Tu misión: agrega el segundo igual que falta para que el sistema compare correctamente.

Misión: Reparar el Sistema de Claves FALLO DE SEGURIDAD
// Las claves del sistema (no las toques)
let claveIngresada = "Matrix2024";
let claveSecreta = "Matrix2024";
// ❌ Esta línea está mal. Corrígela:
let esCorrecto = (claveIngresada claveSecreta);
console.log("¿Clave válida?", esCorrecto);
