Condicionales
if

▶ VIDEO: TOMANDO DECISIONES CON IF (CLASE 5)

Hasta ahora la computadora ejecutaba todo sin pensar. Hoy aprenderá a tomar decisiones: si algo es verdad, haz esto. Si no, haz otra cosa.

¿Qué es un condicional?

Imagina un guardia en la puerta de un edificio. Antes de dejar pasar a alguien, hace una pregunta: "¿Tienes pase?". Si la respuesta es sí, abre la puerta. Si es no, la mantiene cerrada.

El if en JavaScript funciona exactamente igual. Le haces una pregunta al código y él decide qué instrucciones ejecutar según la respuesta. Si la condición es true ejecuta el bloque. Si es false lo salta.

Esto es lo más importante que aprenderás en todo el curso porque casi todo el código del mundo real está lleno de decisiones: si el usuario está logueado muéstrale el perfil, si no redirigelo al login. Si hay saldo procesa el pago, si no muestra error.

La Estructura del if:

if ( condición ) {
// código que se ejecuta si la condición es TRUE
} else {
// código que se ejecuta si la condición es FALSE
}
if / else palabras clave ( ) aquí va la pregunta { } aquí va la acción

Ejemplo real paso a paso:

Supón que quieres que el sistema revise si alguien tiene suficiente saldo para comprar algo que vale $100.

let saldo = 150;
let precio = 100;

if (saldo >= precio) {
  console.log("Compra aprobada ✅");
} else {
  console.log("Saldo insuficiente ❌");
}

// Como 150 >= 100 es TRUE, imprime: "Compra aprobada ✅"

La computadora evalúa 150 >= 100, obtiene true y entra al primer bloque. Si el saldo fuera 50, obtendría false y ejecutaría el else.

⚠️ Las llaves { } son obligatorias

Todo el código que quieras ejecutar dentro del if debe ir entre llaves { }. Si las olvidas, JavaScript solo ejecutará la primera línea y el resto lo ignorará aunque esté indentado. Es uno de los errores más comunes de los principiantes.

// ❌ MAL — sin llaves, solo ejecuta la primera línea:
if (edad >= 18)
  console.log("Mayor de edad");
  console.log("Acceso concedido"); // esto SIEMPRE se ejecuta

// ✅ BIEN — con llaves, ambas líneas dependen del if:
if (edad >= 18) {
  console.log("Mayor de edad");
  console.log("Acceso concedido");
}

La Puerta
Rota

El sistema de seguridad del edificio está fallando. El programador olvidó algo en el if y ahora la puerta no responde correctamente. ¡Encuéntralo!

¿Qué está mal?

El código de abajo tiene un if incompleto. Al programador se le olvidó poner las llaves { } que envuelven el bloque de código. Sin ellas JavaScript no sabe dónde empieza y dónde termina la acción del if.

Tu misión: agregar la llave de apertura { en el lugar correcto, después de la condición. El código ya tiene la llave de cierre }, solo falta la de apertura.

Pista: la llave va justo después del paréntesis que cierra la condición ), antes del console.log.

Misión: Reparar la Puerta PUERTA BLOQUEADA
// ❌ A este if le falta algo. Corrígelo:
let tienePase = true;
if (tienePase == true)
console.log("Acceso concedido. Bienvenido.");
}

Para tener tres niveles necesitarás encadenar los condicionales así: if ... else if ... else. El else if es un if adicional que se evalúa solo cuando el primero fue falso.

// Estructura con else if:
if (condición1) {
  // si condición1 es true
} else if (condición2) {
  // si condición1 fue false pero condición2 es true
} else {
  // si ninguna fue true
}
